# אי המסתורין – הרפתקה בחשבון 🏝️

משחק חשבון לילדים בכיתות א'–ו'. השחקן בוחר גיבור, מפליג בין 10 איים, ובכל אי עובר 10 שלבים של 15 שאלות.
המשחק עובד בדפדפן וניתן להתקנה בטלפון כאפליקציה (PWA).

## מה יש במשחק
- **10 איים** עם סוגי שאלות שונים: חיבור וחיסור, בעיות מילוליות, כפל וחילוק, שאלות מעורבות, חידות היגיון ואיי בוס.
- **התאמה לכיתה** – רמת הקושי עולה לפי הכיתה והשלב (כולל סדר פעולות, חזקות, אחוזים ומשוואות לכיתות ה'–ו').
- **מטבעות וחנות** – דמויות חדשות, 🦜 תוכי (מעלים 2 תשובות שגויות) ו-🧪 שיקוי (פי 2 מטבעות ל-5 שאלות).
- **רצפים והישגים** – בונוס על כל 5 תשובות נכונות ברצף, וחדר גביעים.
- **סרטונים ותמונות ניצחון** לגיבורים גל, ניקול ונועם.

## שמירת התקדמות
ההתקדמות נשמרת בדפדפן של המכשיר (localStorage), לפי שם השחקן או לפי האימייל שהוזן במסך הכניסה.
אין שרת – מחיקת נתוני הדפדפן מוחקת את ההתקדמות.

## חזרה לשלב באמצע
אם יוצאים מהאפליקציה באמצע שלב (או שהטלפון סוגר אותה), ההתקדמות נשמרת. בפתיחה הבאה שם השחקן כבר כתוב, ולחיצה על "התחל" מחזירה בדיוק לאותה שאלה.

## דוח להורים
- בכניסה הראשונה אפשר להכניס מייל של הורה (לא חובה).
- כפתור 👪 במפת האיים, או 📊 ליד כל שחקן בטבלת האלופים, פותח דוח (אחרי שאלת כפל קצרה כדי שילדים לא ייכנסו).
- הדוח מציג: כמה שאלות נפתרו, אחוז הצלחה בניסיון ראשון, זמן תרגול, הצלחה לפי נושא, פעילות לפי יום, ורשימת הטעויות האחרונות (מה הילד ענה ומה התשובה הנכונה).
- "שלח דוח למייל" פותח את אפליקציית המייל עם הדוח מוכן לשליחה; "שתף" שולח אותו לוואטסאפ ועוד.

## מבנה הקבצים
| קובץ / תיקייה | תוכן |
|---|---|
| `index.html` | כל המשחק: עיצוב, מסכים וקוד |
| `sw.js` | Service Worker – שמירת קבצים לשימוש בלי אינטרנט |
| `manifest.json`, `icons/` | הגדרות והאייקונים להתקנה כאפליקציה |
| `maps/` | תמונות האיים |
| `players/` | תמונות הדמויות |
| `win_images/` | תמונות ניצחון (`<שם>_win<מספר אי>.jpg`) |
| `moves/` | סרטוני פתיחה וניצחון |

## הרצה מקומית
```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## פאנל מנהל
5 הקשות מהירות בפינה הימנית העליונה של המסך פותחות את פאנל המנהל (דורש קוד).

## עדכון גרסה
אחרי שינוי קבצים כדאי להעלות את מספר הגרסה ב-`CACHE_NAME` שבקובץ `sw.js`, כדי שמכשירים שכבר התקינו את המשחק יקבלו את העדכון.
